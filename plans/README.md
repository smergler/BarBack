# Plans

Each build plan lives in its own folder:

```
plans/<slug>/
  PLAN.md        the plan (tasks and subtasks with checkboxes)
  BUILD_LOG.md   attempt journal: what was tried, what failed, why
  PROGRESS.md    append-only session log
```

## Checkbox legend

| Marker | Meaning |
|---|---|
| `- [ ]` | todo |
| `- [x]` | done |
| `- [~]` | in progress |
| `- [!]` | blocked |
| `- [>]` | transferred to another plan |

## Plans

| Slug | Was | Notes |
|---|---|---|
| `drink-suggester` | `PLAN.md` | original build plan |
| `protect` | `PLAN_PROTECT.md` | security and metric fixes |
| `harden` | `PLAN_HARDEN.md` | fixes to PROTECT's verification |
| `supabase-keys` | `PLAN_SUPABASE_KEYS.md` | publishable/secret keys, JWKS-only auth |
| `extend` | `PLAN_EXTEND.md` | coverage retrieval, multi-run averaging, token savings |

`STATUS.md` is generated by `.venv/bin/python scripts/plan_status.py`; do not edit it by hand.
